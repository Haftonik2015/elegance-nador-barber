# Elegance Barber Nador

Crée un site vitrine premium, moderne et responsive pour un barber shop à Nador, Maroc.

## IDENTITÉ

Nom : **Coiffeure Elégance Barbier Barbershop**
Arabe : **حلاقة الأناقة**
Adresse : **5 Rue Marrakech, Nador 62000, Maroc**
Téléphone : **+212 681 718 600**
Horaires : **Tous les jours, 10h00–23h00**
Google : **4,8/5 — 83 avis**
Google Maps : https://maps.app.goo.gl/cwN7bzsxgd7NzTCG7

## STYLE VISUEL

Créer un design **haut de gamme, masculin, élégant et minimaliste**, inspiré des meilleurs barbershops modernes.

Palette :

- noir profond
- anthracite
- blanc cassé
- touches de doré très discrètes

Utiliser de grandes typographies élégantes, des photos immersives, beaucoup d'espace, des animations douces et une excellente hiérarchie visuelle.

Éviter le style générique de template, les couleurs vives et les animations excessives.

Le résultat doit donner une impression de **qualité, précision, confiance et élégance**.

## LANGUES

Le site doit être bilingue :

**Français | العربية**

Le français est la langue par défaut.

La version arabe doit être entièrement **RTL**, pas simplement traduite.

## MOBILE

Le site doit être pensé **mobile-first**.

Sur mobile, ajouter une barre fixe avec :

**Appeler | Itinéraire | Rendez-vous**

## RÈGLES IMPORTANTES

Ne jamais inventer :

- prix
- employés
- promotions
- certifications
- réseaux sociaux
- avis clients
- photos réelles
- services non confirmés

Si une information manque, prévoir un emplacement facilement modifiable.

Le site doit être rapide, responsive, accessible, SEO-friendly et visuellement premium.
